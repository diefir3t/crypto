# Crypto Exchange

## Overview

Crypto Exchange is a university team project developed as a simple cryptocurrency exchange platform. The project is designed for educational purposes and focuses on providing a clean user interface and basic exchange functionalities.

The platform supports only three currencies:

* Bitcoin (BTC)
* Tether (USDT)
* Iranian Rial (IRR)

---

## Features

* User Registration
* User Login
* Home Dashboard
* Wallet Management
* Buy and Sell Cryptocurrencies
* User Profile
* Responsive User Interface
